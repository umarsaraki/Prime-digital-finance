Backup & restore

Backups are managed by Cloudflare D1 (Time Travel). To restore: Cloudflare dashboard → Workers & Pages → D1 → your database → Time Travel, or run npx wrangler d1 time-travel restore pdf_usdt_db --timestamp=<ISO time>. For an extra copy, run npx wrangler d1 export pdf_usdt_db --remote --output=backup.sql. There is deliberately no reset button here.
